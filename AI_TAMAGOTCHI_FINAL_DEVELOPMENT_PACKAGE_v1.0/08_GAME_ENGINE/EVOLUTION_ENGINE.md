# EVOLUTION ENGINE

## XP
`Evolution XP = task-derived monotonic credit + goal XP + streak milestone XP + achievement XP`.
All deltas are non-negative; XP and stage never regress.

## Baseline stages
| Stage | Name | Min XP | Status |
|---|---|---:|---|
| E1 | Детеныш | 0 | baseline |
| E2 | Любознайка | 250 | configurable baseline |
| E3 | Исследователь | 750 | configurable baseline |
| E4 | Изобретатель | 2000 | configurable baseline |
| E5 | AI-мастер | 5000 | configurable baseline |

The stage is the highest threshold not exceeding current XP. Threshold changes apply prospectively unless a separate migration decision explicitly authorizes historical handling.

## Branches
One base E1 mascot exists for all users. A user may choose an evolution branch when the relevant evolution flow is available; once chosen the branch is immutable. Branch effects are purely visual/animation/cosmetic and never change Score, HP, streak, goals or ranking.

Final branch-specific art is not frozen (`OD-029`); engine IDs must not depend on invented production art.

## Task-count milestones
The Product mentions possible task-count milestones as examples but does not freeze exact rewards. Stage 7 does not enable or invent them. They may be added later as versioned achievement/content definitions without changing the core XP engine.
