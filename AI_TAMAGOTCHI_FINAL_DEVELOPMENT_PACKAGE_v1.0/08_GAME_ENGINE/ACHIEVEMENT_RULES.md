# ACHIEVEMENT RULES

## Current freeze level
The Product gives an MVP planning orientation of approximately 20–30 achievements, but does not freeze exact achievement IDs, criteria, XP rewards, cosmetics or final art.

Stage 7 therefore freezes only the engine contract:
- achievements are versioned declarative definitions;
- criteria are backend-executable;
- award is idempotent per employee/achievement/version according to definition;
- optional XP reward, if approved, must be a non-negative configured value;
- optional cosmetic reward must reference an approved catalog item;
- user-facing collection shows earned achievements only;
- no coins, currency or shop are introduced.

No placeholder achievement list is promoted to production requirements. `OD-028` remains a non-blocking content/art freeze item.
