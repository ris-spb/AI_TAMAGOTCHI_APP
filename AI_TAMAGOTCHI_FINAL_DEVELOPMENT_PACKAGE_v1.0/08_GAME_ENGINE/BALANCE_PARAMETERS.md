# BALANCE PARAMETERS

**Policy:** current Product values are the implementation baseline. Stage 7 makes them configurable; it does not tune them.

| Parameter | Baseline | Status |
|---|---|---|
| Task Score C1–C5 | 1 / 5 / 15 / 40 / 100 | approved baseline; distribution validation recommended |
| HP no activity | −30 / working day | approved baseline |
| HP gain C1–C5 | +10 / +15 / +25 / +35 / +45 | approved baseline |
| Additional valid task | +2 HP | approved baseline |
| Initial HP | **100 HP** | `DEC-H-002` — RESOLVED_BY_OWNER (option A) |
| Coma active days | 2 | Product rule |
| Coma exit HP | 1 | safe default from historical Product technical recommendation; configurable |
| Goal Annual Score | +15/goal +15 all-three; max 60/month | working baseline; calibrate later |
| Goal Evolution XP | +10/goal +10 all-three; max 40/month | working baseline; calibrate later |
| Evolution thresholds | 0 / 250 / 750 / 2000 / 5000 | working baseline; simulate |
| Streak milestones days | 5 / 10 / 20 / 40 / 80 / 160 | working baseline |
| Streak milestone XP | 5 / 10 / 20 / 40 / 80 / 150 | working baseline |
| Achievement count | ~20–30 | orientation only; catalog not frozen |
| Ambient reactions | 1–2/day | agreed orientation/cap; gameplay-neutral |

All changes to these business values require a new versioned config/rule decision. UI and prompts must read/represent server results rather than duplicate constants.
