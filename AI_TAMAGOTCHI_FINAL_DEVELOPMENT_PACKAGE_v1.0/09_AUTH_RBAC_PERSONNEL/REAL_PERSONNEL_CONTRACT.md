# REAL PERSONNEL INTEGRATION CONTRACT

**Status:** `EXTERNAL_DEPENDENCY`

The application-side contract is frozen, but corporate values are intentionally unknown.

Required before real integration:
- base URL/protocol;
- authentication mechanism and credential provisioning;
- stable employee/directorate subject keys;
- exact personnel-number and phone normalization;
- identity verification request/response schema;
- error taxonomy and rate constraints;
- sandbox/test access;
- network allow-list/connectivity;
- optional delta/full sync protocol and cadence;
- service ownership/SLA/escalation.

Implementation must supply these through adapter/config/secrets without changing Product auth/RBAC semantics. No guessed endpoint or credential is allowed.
