- optional Weather provider if enabled;

## Visual/3D

- final realtime production GLBs remain external;
- optional KTX2 remains external;
- exact final camera/light/performance tuning remains evidence/tuning work;
- approved static fallback is a valid implementation path;
- proxy GLBs are never acceptable final assets.

## Evidence states

Coding AI may report:
- `CODE_DONE`
- `CODE_DONE_EXTERNAL_GATE_OPEN`
- `BLOCKED_EXTERNAL_DEPENDENCY`
- `DEFERRED_NONBLOCKING`

It may not report:
- `PRODUCTION_APPROVED`
- `REAL_PROVIDER_VALIDATED`
- `FINAL_ASSET_ACCEPTED`
- `RESTORE_TEST_PASS`

unless the corresponding real evidence was actually produced and attached.
